Understanding Semantic HTML

Semantic tags give meaning to the structure of a webpage, making it accessible and easy for search engines to crawl.

Key Elements

  • <header>: Introduces the page or section.
  • <main>: Holds unique main content (only 1 per page).
  • <footer>: Contains copyright, links, or contact info.
